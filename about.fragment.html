Fit check

Will it run on your Mac?

We only build for Apple Silicon Macs — any Mac with an M1, M2, M3, M4 or newer chip. Their unified memory lets the AI use nearly all of the computer’s memory, which is what makes big, capable models practical on a desk. How much memory your Mac has decides which models it can run — find it below, then use the checker.

Step 1: find your chip and memory

  1. Click the Apple menu in the top-left corner of the screen.
  2. Choose About This Mac.
  3. Read the Chip line. If it says Apple M1, M2, M3, M4 or newer (any variant, like “M2 Pro”), you’re set. If it says Intel, see the note below.
  4. Read the Memory line — e.g. “16 GB.” That whole number is usable by the AI.

Step 2: check your fit

How much memory does your Mac have?

Intel Mac, Windows or Linux? We don’t build for those — PCs split memory between the computer and the graphics card, and Intel Macs are too slow for these models, so neither can match an M-series Mac without expensive extra hardware. You can still use us: we’ll run the job on our own Mac and send you the results.

Memory guide

What to expect at each amount of memory

Memory on an Apple Silicon Mac. The figures below assume 4-bit quantized models — the format most people run locally — with room left for a working context window.

64 GB 70B (4-bit) Where local output starts to rival premium cloud models, with roughly 40 GB of weights and headroom for a large context on top.
128 GB + 70B at full precision, or large mixture-of-experts models Room to keep several models loaded at once and hold long-running context in memory — the basis for always-on agents.

Why we only work on M-series Macs

Unified memory changes the math

On an Apple Silicon Mac, the chip and its graphics share one pool of memory, so the AI can use nearly all of it. A 64 GB Mac runs models that would otherwise need a data-center graphics card — and a Mac around $2,000 covers most real workloads.

On Windows and Linux PCs, the model has to fit inside the graphics card’s own memory, which tops out around 24 GB on consumer cards. Going bigger means $2,000+ cards or very slow processing. Focusing on one platform also means every setup we ship is one we’ve built and tested on the same kind of machine you have.
